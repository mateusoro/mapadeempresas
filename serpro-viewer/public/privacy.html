Política de Privacidade

Mapa de Empresas API (Custom GPT Action)

Esta política de privacidade descreve como os dados são tratados ao interagir com a API do Mapa de Empresas por meio de um Custom GPT (ChatGPT).

1. Coleta e Uso de Informações

A nossa API funciona exclusivamente como uma interface de consulta de dados de utilidade pública (base de dados do Mapa de Empresas - SERPRO). Não coletamos, armazenamos ou registramos quaisquer dados pessoais dos usuários do ChatGPT.

2. Processamento das Consultas

  • As consultas enviadas pelo ChatGPT consistem em parâmetros de busca SQL estruturados (filtros e projeções).
  • Essas consultas são processadas em tempo real em um banco de dados SQLite local, no modo de leitura (Read-Only).
  • Nenhum histórico de consultas ou dados pesquisados é guardado de forma persistente pela API.

3. Compartilhamento de Dados com Terceiros

A API opera de forma fechada e isolada. Não compartilhamos dados com nenhum parceiro ou serviço externo de terceiros.

4. Segurança da Informação

A conexão entre o OpenAI/ChatGPT e o nosso servidor é totalmente criptografada via protocolo HTTPS por meio de um túnel seguro fornecido pela Cloudflare.

5. Alterações nesta Política

Esta política pode ser modificada a qualquer momento para refletir atualizações no serviço, mantendo sempre o compromisso de não-coleta de informações privadas.
